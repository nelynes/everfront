Launching games
  EverFront starts games the same way the EverDrive's own menu does, so
  that saves, the clock and the in-game menu behave the same. It contains
  none of the EverDrive menu's code: the in-game menu is read from the
  cart's own firmware when a game starts.
  Game Boy, Game Boy Color, NES, Master System and Game Gear games run
  through the emulators you put in the EverDrive's own edgba/edapp
  folders; none are included.

Label art is not included. Label scans are the games' publishers' artwork;
each user builds their own label packs from their own scans.
